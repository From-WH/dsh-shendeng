# 神灯 · Shen Deng

> 画靶射箭。没有靶，就无的放矢。

一个 DeepSeek Harness 插件：**把输入框里的提示词增强成更完整、更准确的执行指令**。

输入框旁的增强按钮会读你的工作区，把「那个项目」「这个文件」之类的指代换成真实存在的名字，并补齐执行时真正会卡住的信息，然后把结果直接写回输入框——不满意可以一键撤销。

需求越清晰，AI 的效率和准确率越高。神灯把这件事提前到发送之前，而不是在返工几万 token 之后。

## 安装

在 DeepSeek Harness 的插件管理器中安装本目录，或手动加入 profile：

```yaml
- insert:
    - id: shen-deng
      name: 'dsh-shendeng'
      config: {}
```

## 提供什么

### 输入框旁的增强按钮

输入框右侧有 `[灯] 增强提示词`。输入内容后点一下：

1. 读取当前提示词
2. 结合工作区结构改写成完整指令
3. 直接替换输入框内容，图标变成撤销

**结合工作区**是它和普通改写器的区别：你说「帮我改那个插件」，它不会回你「（落点待定）」，而是指出工作区里真实存在的 `desktop-pet/` 和 `shen-deng/` 两个候选，并说明两者结构相同，需要你指明。

### `lamp_rewrite` — 增强提示词（工具）

按钮背后的同一个能力，也作为工具开放给模型：传一段提示词，返回增强后的文本和仍待补充的维度。浏览器不能直接调模型，所以按钮走的是 `/lamp rewrite <提示词>` 命令，命令再调用这条路径。

### `lamp_refine` — 提示词检查

按六个维度检查提示词：**交付物、落点、受众与语气、硬约束、验收标准、范围**。
输出：缺哪几项、每项一个推荐默认、一份填好的工作说明。

内置**意图与指代识别**：需求里点名了工作区已有目录（如 "把 shen-deng 再优化一下"），落点自动判定为"改现有"，不再反问"要新建还是改现有"；说"改一下"但没点名时，会列出能对上号的候选。

### `lamp_scan` — 工作区结构

一次有界扫描：深度优先目录树、文件类型统计、项目清单摘要。替代逐个读文件、反复搜索的探索流程。

### 开关

**默认点亮**，装上即可用，不需要先执行任何命令。`/lamp off` 关闭后增强按钮不再生效、提示词段落也随之停止注入；`/lamp on` 重新开启。

关闭是纯粹的自愿行为：不想要这个按钮的人可以关掉，而不是所有人都得先发现怎么打开。

### 维度可配置

**设置 → 神灯**：图形界面增删改维度，保存即生效，无需重启。每维五个字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识（必填） |
| `label` | 显示名 |
| `match` | 匹配短语列表；`/…/` 形式按正则处理（必填） |
| `ask` | 向用户提出的问题 |
| `suggest` | 模型可直接采用的默认 |

配置了 `dimensions` 就整体替换内置六维；不配置或留空即用默认。

也可以直接写在 profile 的 `cordis.patch.yml` 里：

```yaml
- id: shen-deng
  name: 'dsh-shendeng'
  config:
    dimensions:
      - id: tone
        label: 调性
        match: [幽默, 严肃, 温暖]
        ask: 要什么调性？
        suggest: 默认克制、少形容词。
```

## 设计取舍

- **默认可用**：装上即可用，不需要先执行任何命令；不需要时用 `/lamp off` 关掉，提示词段落也随之不再注入。
- **零运行时依赖**：Schemastery 从本地 vendor 引入（linked 包解析不到 profile 依赖）；投影校验是手写的最小实现。
- **不加新事件类型**：开关状态从框架已有的 `command/run` + `command/done` 事件折叠而来，重开、fork 都能还原，旧版本读日志也无害。
- **文字颜色全走主题 token**：深浅主题下都可读。

## 边界

- 只在已有会话显示（`conversation.input.right` 是 session scope，新对话发出首条消息后出现）。
- 只读工作区顶层结构，不读代码内容；指代识别靠名字对号。
- 匹配语料以中文为主，英文提示词的识别率会低一些。

## 开发

```bash
npm test
```

单元测试在当前 Node 下运行；`test/cordis.integration.mjs` 用已安装的 DeepSeek Harness 的 Electron 二进制加载真实 Cordis 上下文，验证依赖守卫（`inject` 声明缺失时插件必须不激活而不是半激活）。没装 App 时该步骤自动跳过。

```
test/
  helpers.mjs            临时工作区、真实磁盘 fs provider、Host 上下文替身
  audit.test.mjs         六维检查、意图识别、指代解析、brief 生成
  tools.test.mjs         三个工具与 /lamp 的边界行为、配置回退
  projections.test.mjs   开关与用量投影的折叠逻辑
  client.test.mjs        浏览器半边的注册、渲染、locale 覆盖
  cordis.integration.mjs 真实 Cordis 依赖守卫
```
